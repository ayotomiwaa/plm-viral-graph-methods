# Scripts

This directory contains lightweight reusable workflow entry points copied from local experiment folders.

The scripts are organized by role:

- `preprocessing/`: embedding and input-preparation helpers
- `graph_construction/`: graph-building workflows for Hamming and embedding representations
- `validation/`: lineage, tree, temporal, and geodesic validation scripts
- `summaries/`: summary-table builders

Most scripts preserve their original command-line interfaces. Run from the repository root and inspect each script's `--help` output before rerunning an analysis.
